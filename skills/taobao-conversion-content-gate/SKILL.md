# 淘宝成交内容门禁

用转化漏斗决定每个内容模块存在的理由。主图负责争夺点击；本 Skill 用主图后续图、SKU、详情页、真实评价结构、问大家和客服话术共同搭建可兑现的使用想象，承接理解、选择、信任、加购、支付与预期管理。

## 固定输入

1. 读取已确认的 S3 链接策略及转化漏斗、产品事实、当前运营政策、主图已确认命题、用户偏好和当前执行方案。
2. 缺少内部事实时列成问题请用户确认；确认后登记为用户确认事实并按其适用范围执行。
3. 策略或主图承诺未确认时停止，不得通过详情页反推或补救错误定位。
4. 使用 [成交内容策划卡](references/conversion-content-card.md) 记录关卡。

## 成交漏斗

按顺序承接：

`点击 → 理解并继续浏览 → 选对SKU → 相信结果 → 消除顾虑 → 加购/支付 → 正确预期并减少退款`

每个模块只设一个主要任务，并写清消费者此刻的问题、需要发生的心理变化、视觉证据、下一步动作、指标和失败信号。不能说明漏斗作用的内容直接删除。

所有核心内容都先完成 `人群 → 场景 → 痛点 → 改变`，再补产品作用和可信证据。不得把产品功能依次念一遍，也不得用“材质优良、做工扎实、性价比高”代替生活变化。

## SKU标准：简约但不简单

SKU的任务是让消费者快速选对，而不是把所有信息压进小图。

必须具备：

- 统一、可扫读的SKU命名规则；
- 消费者做选择所需的关键差异，而非内部型号差异；
- 对应产品外观、核心配置/数量、适用情境或人群；
- 到手内容、价格差异和必要条件可核对；
- 名称、SKU图、详情说明、购物车和客服口径一致；
- 不看详情、不问客服也不会因为缺少关键信息而选错。

默认优先级：`版本/核心差异 → 适合谁或什么场景 → 到手关键内容`。省略不影响选择的信息。SKU超过消费者可轻松比较的数量时，应合并、分组或拆链接。

## 详情页标准：先让图片讲明白

详情页不是产品说明书，而是成交叙事。先做无文案视觉Storyboard，再补文案。

推荐顺序：

1. 延续主图承诺，让消费者确认“点对了”；
2. 呈现目标场景和当前问题；
3. 展示产品带来的更高结果；
4. 用结构、过程、实物、对比或资质证明为什么可信；
5. 帮助选择SKU并说明到手内容；
6. 回答安装、耗材、维护、服务、物流和风险；
7. 汇总Offer并给出明确购买动作；
8. 管理使用预期，减少错买、退货和差评。

### 无文案看图测试

遮住标题、正文和营销文案后，目标消费者仍应通过场景、动作、产品关系、前后状态、结构证据和视觉顺序判断：

- 这一屏在讲什么问题或结果；
- 产品在其中起什么作用；
- 结果朝哪个方向变化；
- 下一屏为什么值得继续看。

文字负责命名、量化、限定和增强说服，不负责抢救一张语义不成立的图片。参数、服务和合规条件等无法纯画面精确表达的内容，可保留必要文字，但必须有图示、流程、实物或证据载体，禁止使用无关氛围图托文案。

### 想象素材协同

- 后续主图/视频：让消费者看见使用动作与第一层结果；
- 详情页：展开从当前痛点到使用后改变的完整过程；
- SKU：把使用场景和需求映射到正确版本；
- 真实评价：按人群、场景、顾虑、使用过程和改变组织真实证据，不得伪造买家评价；
- 问大家/客服：先询问和识别使用场景，再给适配建议、事实证据和风险说明，不照读参数表。

同一核心想象由不同内容分工证明，不重复粘贴同一句卖点。

## 五个关卡

### C1：漏斗内容地图

只交付每层问题、心理变化、人群—场景—痛点—改变、承接内容、证据、动作、指标和缺口。确认后继续。

### C2：SKU决策系统

只交付SKU结构、命名规则、必要信息、SKU图骨架、错选风险和合并/拆分建议。确认后继续。

### C3：无文案详情Storyboard

先用缩略草图/画面描述展示视觉叙事，不写正式营销文案。逐屏通过无文案看图测试后确认。

### C4：文案与正式素材

在已确认视觉叙事上添加标题、证据、限定条件和CTA。文案与画面必须互证；没有对应画面的主张不得添加。

### C5：成交终检

统一检查主图承诺、SKU选择、详情证明、Offer、客服口径和政策；验证手机端顺序、可读性、跳转、优惠、库存与测试下单条件。

用户的简短确认只授权进入当前已说明的下一关。

## 自动停止条件

- 内容没有绑定漏斗阶段和消费者下一步动作；
- SKU看起来干净，但缺少会导致选错或咨询的必要信息；
- SKU堆满参数，却不能快速看出版本差异和适合谁；
- 详情页先写完整文案，再找装饰图片贴上去；
- 遮住文案后只剩通用厨房、装饰水花或无关生活场景；
- 图片与文字表达两个不同卖点；
- 详情页重复主图口号，却没有增加证据、选择帮助或风险消除；
- 详情页像说明书一样按产品功能顺序排列，没有形成从痛点到改变的使用叙事；
- 只说材质、做工、参数或性价比，消费者无法想象生活具体变好在哪里；
- 场景图中产品没有参与真实使用动作，只是背景陈列；
- 编造、暗示或改写不存在的买家评价来补证据；
- 首图承诺无法被产品、SKU、详情或Offer兑现；
- 为减少页面长度而删除影响选择、成交或预期管理的必要信息。

命中任一项时，退回对应关卡。
