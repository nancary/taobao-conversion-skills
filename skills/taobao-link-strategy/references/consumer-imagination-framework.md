# 可兑现的使用想象

## 一、目的

线上购物缺少触摸、试用和现场解释。电商策略要用内容帮助消费者提前完成一次心理试用：认出自己、进入场景、感到现状问题、看见产品介入，并想象拥有后的具体改变。

“让消费者想象”不等于编故事。想象必须由真实产品能力、当前服务和可核验证据兑现。

## 二、六层成交想象桥

| 层级 | 必答问题 | 弱表达 |
| --- | --- | --- |
| 人群 | 谁在什么条件下最需要 | 家庭用户、品质人群 |
| 场景 | 何时、何地、正在完成什么任务 | 厨房使用、日常生活 |
| 痛点 | 当前动作造成什么麻烦、损失或妥协 | 不方便、有痛点 |
| 改变 | 入手后动作、时间、空间、感受或生活状态哪里变好 | 体验升级、品质生活 |
| 产品作用 | 产品通过什么机制促成改变 | 材质优良、做工扎实 |
| 可信证据 | 什么实物、演示、数据、服务或真实体验能证明 | 性价比高、值得信赖 |

前四层负责产生购买欲望，后两层负责让欲望可信。顺序不能颠倒成“先念功能，再硬找场景”。

## 三、功能利益翻译链

对每项准备使用的功能执行：

`产品事实 → 作用机制 → 使用动作 → 场景结果 → 生活改变 → 证明方式`

如果只能写到产品事实或机制，该信息只能进入参数/证据模块，不能承担主命题。

例如，“容量大、保温久”不是终点；终点应是消费者在具体一天中减少了什么动作，并持续得到什么感受。“结实耐用”也不是终点；要继续解释它让哪个空间中的什么混乱得到长期改善。

反例：若把“大容量”翻译为“出门不用频繁补充”，但目标消费者原本就没有频繁补充的动作，则场景结果没有胜过现状，不能承担主钩子。

## 四、心理试用测试

让未参与策略的人看完核心表达后回答：

1. 这在说谁，我是否觉得“像我”；
2. 我会在什么具体时刻使用；
3. 它替代我现在的哪个动作或妥协；
4. 产品如何进入这个场景，而不是只在旁边摆着；
5. 使用后哪一个可感知状态发生变化；
6. 我凭什么相信这份变化；
7. 为什么现在值得购买，而不是继续原来的做法。

前五题任一答不出，说明想象不完整；第六题答不出，说明是空洞承诺；第七题答不出，说明改变动力不足。

## 五、内容协同

- 主图：截取最有辨识度的“人群/场景/痛点/改变”瞬间，争夺点击。
- 后续主图与视频：补充使用动作、变化过程和第一层证据。
- SKU：把不同人群或使用需求准确映射到可购买版本。
- 详情页：完整展开从现状到改变的视觉叙事，并逐步补足机制、证据、Offer和风险逆转。
- 真实评价：由真实买家的场景和结果证明“别人实际拥有后确实如此”；不得编造或改写成虚假证言。
- 问大家/客服：围绕消费者的实际场景回答适配、安装、成本和风险，使想象落到可执行购买决定。

各内容必须讲同一份核心想象，但承担不同证明任务，禁止重复一组口号。

## 六、表达模板

模板用于检查结构，不用于机械套句：

`[具体人群]在[具体场景]，原本需要/担心[具体痛点]；产品通过[真实作用]，让[使用动作或状态]变成[可感知改变]，并由[证据]证明。`

删掉任意形容词后仍然成立，通常比堆“高端、扎实、优质、超值”更有说服力。
