# 淘宝链接策略

先决定“为谁、替代什么、凭什么赢、卖什么完整价值”，再决定主图和详情页怎么表达。不要在本 Skill 内制作风格板、Storyboard、文案成稿或图片。

## 开工顺序

1. 读取当前项目可用的用户偏好、产品事实、经营政策、品牌事实、链接定位和历史验证记录。项目没有固定文件结构时，先建立一份最小事实清单，不要假设任何内部路径存在。
2. 写清本轮边界：只研究/只给候选策略/形成正式策略。用户简短确认只授权已说明的下一关。
3. 按 [来源与适配说明](references/source-adaptation.md) 使用框架；不要机械堆 SWOT、五力或营销术语。
4. 制定消费者命题时读取 [可兑现的使用想象](references/consumer-imagination-framework.md)，先完成“人群—场景—痛点—改变”，再把功能和参数降到证明层。
5. 使用 [链接策略卡](references/link-strategy-card.md) 记录证据、选择和淘汰原因。

## 证据底座

把信息分为 `已确认事实`、`外部观察`、`合理推断`、`待验证假设`，不得混写。

缺少内部产品、政策或经营事实时，把缺口改写成可直接回答的问题交给用户。用户明确确认后，将答案登记为 `用户确认事实`，记录原问题、答案、确认日期、适用链接/产品和有效期；在适用范围内按事实执行，不得反复追问。外部市场表现仍需外部证据，用户确认只能将其转为项目采用的判断或假设，不能伪装成平台客观数据。

正式策略至少需要：

- 当前产品与政策事实；
- 当前淘宝/天猫关键词、价位和产品形态证据；
- 至少 8 个同平台直接竞品样本，其中至少 3 个有销量、付款人数、榜单或其他可核验表现信号；没有表现证据时只能称“表达样本”；
- 每个准备主攻的消费者分层至少 5 条独立信号，来源可为评价、问大家、客服问题、退款/差评、访谈或公开讨论；不足时必须标记为假设；
- 至少 3 类替代方案：不购买/维持现状、跨品类解决方式、直接竞品。

淘宝页面受登录、个性化和活动影响时记录日期和限制。品牌官网可用于产品和视觉事实，不能代替淘宝货架结论。

## 消费者机会

先按价格带、使用情境和购买任务分层，再看人口属性。每个分层必须写：

- 情境与触发事件；
- 功能、情绪和社会任务；
- 当前怎么解决；
- `Push`：现状哪里不满；
- `Pull`：新方案带来什么更高结果；
- `Habit`：为什么继续旧做法；
- `Anxiety`：为什么不敢换；
- 可接受的价格、安装、维护和能力边界。

如果 `Push + Pull` 不足以超过 `Habit + Anxiety`，该人群不是当前主攻对象。若“不买该商品”也能得到同样结果，重写购买任务，不得强行制造需求。

最多保留 3 个候选分层，按需求强度、未满足程度、我方适配、证据强度、竞争可赢性和经营价值评分，只选 1 个主攻分层，可保留 1 个次级承接分层。

## 搭建可兑现的使用想象

线上消费者无法触摸实物，策略必须用主图、详情页、真实评价、问大家和客服话术共同补足体验缺口。所有核心表达必须先回答四点：

1. **人群**：谁会在此刻强烈需要，不用空泛人口标签；
2. **场景**：在什么时间、地点、任务和触发下使用；
3. **痛点**：当前做法造成什么具体麻烦、损失、焦虑或妥协；
4. **改变**：入手并使用后，动作、时间、空间、感受或生活状态具体改善在哪里。

再补两层使想象可信：产品在改变中承担什么作用；由什么结构、性能、实物、服务或真实体验证明。使用以下翻译链，不得从功能直接跳到空泛形容词：

`产品事实 → 作用机制 → 具体场景中的消费者结果 → 可感知的生活改变 → 可见证据`

“材质优良、做工扎实、性价比高、性能强”等词不能单独构成策略；参数只能解释为什么结果成立。若消费者看完仍无法想象何时使用、如何使用、替代什么、生活哪里变好，判定为产品说明书表达，退回消费者机会阶段。

## 货架与竞争

对直接竞品记录：价格/权益、第一钩子、目标人群、核心承诺、证明方式、评论中的获得与失望、品牌/销量优势、未回答问题。

将同屏表达分为：

- `入场项`：用户预期本品类应该具备；
- `拥挤项`：多人都在高频争夺，除非我方明显更强，否则不能定位；
- `空缺项`：消费者在意、竞品没有讲清且我方有证据；
- `伪空缺`：同行不讲是因为需求弱、风险高或产品无法兑现。

同时比较现状、跨品类替代和竞品。不要只问“比竞品多什么”，还要问“为什么消费者现在要改变”。

## 形成策略

使用最小必要框架，不写框架展示稿。

1. **诊断**：真正阻碍点击或成交的核心矛盾，只允许一个。
2. **指导方针**：决定在哪里竞争、放弃什么、用什么优势赢。
3. **一致行动**：主图、SKU、详情页、价格/权益、信任证据和验证动作必须互相支持。
4. **定位**：谁，在什么情境，为了什么进步，正在替代什么；我方承诺什么结果，靠什么独特属性和证据成立。
5. **可防守性**：竞品能否一周内改文案复制；若能，我方是否仍有产品、成本、服务、供应、证据或链接矩阵优势。

## 建立转化漏斗

S3 必须先建立本链接的转化漏斗，再分配内容，不得把主图、SKU和详情页当作彼此独立的设计任务：

`货架曝光 → 点击 → 理解并继续浏览 → 选对SKU → 加购/咨询 → 支付 → 收货满意并减少退款`

每一层都写清：目标消费者此刻的问题、需要发生的心理变化、负责承接的内容、可信证据、下一步动作、核心指标和失败信号。任何素材必须绑定一个主漏斗任务；同时承担多个互相冲突任务时，拆分或删减。

- 主图：围绕目标消费者的点击，与同屏同行争夺注意力并兑现一个明确点击理由。
- 后续主图：延续首图承诺，推动理解、兴趣与继续浏览。
- SKU：简约但不简单，让消费者用最少信息选对，不依赖客服补充关键差异。
- 详情页：围绕成交组织视觉叙事，依次完成理解价值、相信证据、选择方案、消除风险和行动。
- 真实评价：用真实消费者的场景、顾虑、使用过程和改变验证想象；没有真实证据时标记缺口，禁止编造买家评价。
- 客服/问大家：先理解人群、场景和顾虑，再把产品能力翻译成购买建议；同时反向暴露页面缺口。

定位不能同时占据多个互相冲突的心智。主动写明不服务谁、不解决什么、不承诺什么。

## 构造淘宝 Offer

把 Offer 看作完整成交条件，不等于赠品文案。至少检查：

- 核心产品结果；
- SKU与价格梯度；
- 安装、发货、售后和风险逆转；
- 首套耗材、赠送条件、长期耗材成本与购买入口；
- 真实、可兑现的活动和时效；
- 在店铺链接矩阵中的角色，避免同店互抢。

用四个杠杆检查价值：结果是否更想要、可信度是否更高、获得结果是否更快、消费者付出的时间/精力/风险是否更低。平台促销不能弥补产品价值空缺，禁止虚假稀缺、虚构原价、假背书和不可兑现保证。

## 候选与决策

最多输出 2 条策略路线，每条都必须是完整选择，不是换一句标题。分别说明主攻人群、现状替代、核心承诺、独特优势、证据、Offer、放弃项、风险和验证方式。

评分权重：

| 维度 | 权重 |
| --- | ---: |
| 消费者改变动力 | 25 |
| 同屏差异与空缺真实性 | 20 |
| 证据强度 | 20 |
| 我方可防守优势 | 15 |
| 完整Offer价值 | 10 |
| 执行与经营可行性 | 10 |

消费者改变动力、证据强度或商业可兑现性任一低于 70，直接淘汰，不能用总分抵消。推荐唯一路线并说明为什么另一条不应先做。

## 三个确认关卡

### S1：证据与机会地图

只交付证据缺口、消费者分层、替代方案、货架共性与真实机会。暂停等待用户确认研究判断。

### S2：候选策略

只交付最多 2 条路线、评分、淘汰原因和唯一推荐。暂停等待用户选择或修正。

### S3：正式链接策略

将确认路线写成唯一当前策略：诊断、指导方针、一致行动、定位、人群—场景—痛点—改变、Offer、转化漏斗、内容任务分配和测试计划。保存为当前链接策略后，主图任务交给 `$taobao-main-image-gate`，SKU与详情页任务交给 `$taobao-conversion-content-gate`。

## 自动停止条件

- 只有市场报告或官网，没有当前淘宝货架证据；
- 把“家庭用户”“追求品质”当作消费者分层；
- 没有研究不购买、现有习惯和跨品类替代；
- 用参数、低价、赠芯或视觉风格直接代替策略；
- 把热销与表达优秀混为一谈；
- 候选优势只能靠换文案获得，缺少产品或经营证据；
- 一次给出超过 2 条主路线，或试图同时服务所有价位；
- 用户尚未确认策略就进入主图、风格板或详情页制作；
- 用漂亮的完整方案掩盖证据不足。
- 没有先画出转化漏斗，就直接分配主图、SKU或详情页内容。
- 素材没有对应漏斗任务、消费者疑问和下一步动作。
- 策略从参数、材质、做工或“性价比高”开始，而不是从人群、场景、痛点和改变开始。
- 场景只是装饰背景，消费者无法在脑海里预演使用动作和生活变化。
- 描绘的生活改变无法由产品能力、服务或证据兑现。

命中任一项时退回对应上游步骤，并明确缺少什么。
