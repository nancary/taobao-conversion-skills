# 淘宝好主图标准与信息模板

本文件定义“好主图”的正向标准。门禁负责淘汰错误方向，本标准负责把通过的方向做到足够有竞争力。

## 一、主图唯一任务

主图服务转化漏斗的 `货架曝光→点击`。它要让一个明确目标消费者在同屏竞品中更快注意到我方，并因为一个与自己相关、可相信、可继续兑现的理由点击。

主图不是详情页缩略版，不负责讲完所有参数、权益和品牌故事。

## 二、九项正向标准

| 标准 | 合格表现 | 不合格表现 |
| --- | --- | --- |
| 目标人群明确 | 能说出预算、场景、购买任务和当前替代 | “家庭用户”“注重品质” |
| 单一点击理由 | 第一眼只有一个主要利益，其余信息负责证明 | 参数、价格、赠品、服务同时抢层级 |
| 心理试用 | 产品进入具体动作，消费者能预演拥有后的改变 | 场景只是背景，产品只在旁边陈列 |
| 一秒识别 | 立刻看懂卖什么、给谁、带来什么结果 | 先读长文案才明白 |
| 同屏注意力 | 320px下形成独特轮廓、色块、场景或结果证据 | 只在大图中精致，同屏消失 |
| 消费者结果 | 先表达得到什么，再说明产品有什么 | 把容量、功率、级数等参数当目的 |
| 画面自证 | 遮字仍能看出利益方向，文案能指向画面证据 | 通用厨房背景加一句无关卖点 |
| 产品保真 | 产品为主体，结构、标签和比例可信 | 抠图感、标签小字消失、外观变形 |
| 漏斗承接 | 点击后SKU、详情和Offer继续兑现同一承诺 | 首图高承诺，后续没有证明或无法购买 |

任何一项不合格，不提交为正式主图。

## 三、四类信息模板

模板只规定信息关系，不规定颜色、字体、构图和固定版式。先按策略选择一个，不得为了凑A/B测试强行多选。

### 模板A：结果场景型

- 适用：消费者能直观看到使用后的生活结果。
- 画面骨架：目标场景/人物动作 → 可见结果 → 真实产品 → 一句结果钩子 → 次级证据。
- 点击动力：消费者先认出“这是我的场景”，再看到比当前做法更好的结果。
- 淘汰条件：没有真实可视结果，只能靠氛围图和文案解释。

### 模板B：改变对比型

- 适用：旧做法的麻烦与新结果存在强烈、真实、可视差异。
- 画面骨架：当前状态 → 改变后的状态 → 产品/机制作为因果桥梁 → 一句差异钩子。
- 点击动力：把消费者已有的不满具体化，让改变的收益一眼成立。
- 淘汰条件：旧做法其实不痛，或对比夸大、不可验证。

### 模板C：证据先行型

- 适用：高顾虑、高客单或消费者首先怀疑效果，且我方拥有独特强证据。
- 画面骨架：结果结论 → 可视证据/结构/权威事实 → 真实产品 → 低层级权益。
- 点击动力：在同屏口号中先建立“这家有凭据”的信任优势。
- 淘汰条件：证据是同品类标配、看不懂，或只能依赖长文字。

### 模板D：Offer决策型

- 适用：目标人群价格敏感，且我方完整成交条件确有相对优势。
- 画面骨架：适用人群/场景 → 核心产品结果 → 到手方案或低风险条件 → 产品主体。
- 点击动力：降低决策成本，而不是只靠低价制造点击。
- 淘汰条件：只剩价格、赠品或虚假稀缺；产品价值本身没有成立。

## 五、验收方式

1. 与至少5个同搜索词、同价位、同形态竞品缩至320px并排。
2. 让未参与制作的人观看1秒后回答：卖什么、给谁、在哪用、解决什么、使用后哪里改变、为什么要点。
3. 遮住全部文案，判断画面是否仍指向核心利益。
4. 把产品换成任一竞品，若仍完全成立且我方没有更强证据，则退回命题。
5. 对照后续SKU和详情页，确认点击承诺可以继续被证明和购买。
